# Abreu  Beauty & Collection 

Tienda en lineal de productos de belleza y artículos de colección, desarrollada como proyecto de Ingeniería en software.

## Descripción 
Plataforma web que permite a los clientes conocer los productos disponibles, consultar sus precios y realizar pedidos de manera sencilla.

## Funcionalidades principales
-Catalogo de productos con imágenes, precios y descripciones
-Carrito de compras 
-Formulario y proceso de pedidos 
-Sección especial de artículos de colección
-Diseño adaptable a teléfonos y computadoras

## Metodología y herramientas
-Planificación y seguimiento con Kanban en GitHub Projects
-Control de versiones con Git y GitHub
-Etapas de proyecto: Requisitos, Diseño, Desarrollo, Documentación 

## Autor 
Proyecto realizado para la asignatura de Ingeniería en Software
